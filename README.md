# 분포 변화 환경에서 탈옥 탐지기의 갱신 방식 비교

빅데이터시각화 PBL 04조 프로젝트 저장소입니다.

## 프로젝트 소개

대규모 언어모델(LLM)의 안전장치를 우회하는 **탈옥(jailbreak) 프롬프트**는 시간이 지나면서 계속 형태가 바뀝니다. 그래서 한 시점의 데이터로 학습한 탐지 모델은 시간이 갈수록 성능이 떨어질 수 있습니다.

이 프로젝트는 **과거 탈옥 프롬프트로 학습한 탐지 모델이 처음 보는 탈옥 프롬프트를 지속적으로 탐지하려면, 모델을 어떤 방식으로 갱신하는 것이 효율적인가**를 비교합니다.

## 데이터

- **JailbreaksOverTime** ([Hugging Face](https://huggingface.co/datasets/djapp18/JailbreaksOverTime), [논문](https://arxiv.org/abs/2504.19440))
- 23,558개 프롬프트(탈옥 3,902개, 정상 19,656개), 43주 분량
- 주요 변수: `uid`, `prompt`, `source`, `timestamp`, `label`(1=탈옥, 0=정상)


## 실험 설계

- **시간 구조:** 첫 4주(2,050개)는 초기 학습에, 나머지 39주(21,508개)는 평가에 사용합니다.
- **평가 방식(test-then-train):** 매주 새 프롬프트를 현재 모델로 먼저 판정한 뒤, 정해진 주기(1주, 2주, 4주)마다 모델을 갱신합니다.
- **기본 탐지기:** TF-IDF(단어 1·2-gram) → Truncated SVD(96차원) → 로지스틱 회귀. 판정 임계값은 0.5로 고정합니다.

### 비교한 갱신 방식

| 구분 | 방식 | 설명 |
|---|---|---|
| 기준선 | A1. 적응 없음(하한선) | 초기 모델을 갱신하지 않음 |
| | A2. 전체 재학습(상한선) | 모든 프롬프트를 실제 라벨로 재학습 |
| 라벨 없이 적응 | B1. 자기학습 | 모델 판정 결과 전체를 추정 라벨로 사용 |
| | B2. 자기학습 + 확신도 임계값 | 확신도 0.9 이상인 판정만 사용 (FixMatch) |
| | B3. 자기학습 + 이전 결과 이어서 학습 | 직전 모델에서 출발해 추정 라벨만으로 학습 |
| | B4. 메모리(kNN) | 가장 비슷한 과거 프롬프트 10개로 판정 |
| 라벨 일부 사용 | C1. 무작위 라벨링 | 매 주기 k%를 무작위로 골라 실제 라벨 공개 |
| | C2. 불확실도 라벨링 | 모델이 가장 헷갈려하는 k%를 골라 실제 라벨 공개 |
| 제안 방식 | R1. 혼합 라벨링 | 무작위 20% + 불확실도 40% + 라벨 보유 문서에서 가장 먼 문서 40% |

검수 비율 k는 1%, 5%, 10%입니다.

### 평가 지표

재현율(Recall), 오탐률(FPR), 정밀도(Precision), F1을 계산하고, 방식 간 차이는 4주 단위 블록 부트스트랩과 Holm 보정으로 검정합니다.
